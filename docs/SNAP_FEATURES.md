# Features ✨

Snap organizes storefront functionality into distinct features, each backed by its own controller. Pick the features your integration needs — most projects use a combination of several.

- **[Search](https://athoscommerce.github.io/snap/snap-search)** — search results and category/PLP pages.
- **[Category Pages](https://athoscommerce.github.io/snap/snap-category-pages)** — scoping the Search feature to a specific category using a Background Filter.
- **[Autocomplete](https://athoscommerce.github.io/snap/snap-autocomplete)** — search-as-you-type suggestions and results.
- **[Recommendations](https://athoscommerce.github.io/snap/snap-recommendations)** — product recommendation carousels.
- **[Finder](https://athoscommerce.github.io/snap/snap-finder)** — guided-selling / product finder experiences.
- **[Tracking](https://athoscommerce.github.io/snap/snap-tracking)** — Beacon 2.0 event tracking across all features.
