# Features

Snap organizes storefront functionality into distinct features, each backed by its own controller. Pick the features your integration needs — most projects use a combination of several.

- **[Search](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_SEARCH.md)** — search results and category/PLP pages.
- **[Category Pages](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_CATEGORY_PAGES.md)** — scoping the Search feature to a specific category using a Background Filter.
- **[Autocomplete](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_AUTOCOMPLETE.md)** — search-as-you-type suggestions and results.
- **[Recommendations](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_RECOMMENDATIONS.md)** — product recommendation carousels.
- **[Finder](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_FINDER.md)** — guided-selling / product finder experiences.
- **[Tracking](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_TRACKING.md)** — Beacon 2.0 event tracking across all features.
