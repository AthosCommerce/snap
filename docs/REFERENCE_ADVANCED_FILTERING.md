# Advanced Filtering 🧪

Snap supports two ways to pre-apply a filter without the shopper explicitly selecting it — pick the one that matches whether the filter should be visible and removable, or invisible and locked in.

- **[Background Filters](https://athoscommerce.github.io/snap/snap-background-filters)** — invisible to the shopper and cannot be removed. Best for category pages or restricting product visibility by user group.
- **[Foreground Filters](https://athoscommerce.github.io/snap/snap-foreground-filters)** — applied to the URL like any shopper-selected filter, visible in the UI, and removable. Best for pre-applying a filter (e.g. from a marketing link) that the shopper should still be able to clear.
