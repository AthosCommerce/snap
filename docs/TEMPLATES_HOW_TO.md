## Templates How Tos

Step-by-step guides for common Snap Templates tasks. Each how-to has its own page. For the full list of configuration options, see [Templates Config](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_CONFIG.md) and [Templates Theming](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_THEMING.md).

### Layout Options & Layout Selector

Let shoppers switch the search results grid between pre-defined layouts (for example 4, 3 or 2 columns) with the `layoutOptions` prop and the `layoutSelector` toolbar module, including a different set of options per breakpoint.

See [Layout Options & Layout Selector](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_LAYOUT_OPTIONS.md).

### Using Theme Variables in Styles

Use the theme's breakpoint values in `theme.style` media queries, so your CSS changes at the same widths as your responsive theme overrides.

See [Using Theme Variables in Styles](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_THEME_VARIABLES.md).

### Customizing Toolbar Layouts

Choose which modules (sort, per page, pagination, banners and more) render in the search templates' top, middle and bottom toolbars, and in which order.

See [Customizing Toolbar Layouts](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_TOOLBAR_LAYOUTS.md).

### Customizing Autocomplete Layouts

Arrange the sections of the autocomplete templates (terms, facets, results, banners, the search input) with a prebuilt or custom `layout`, and size the results grid with `columns` and `rows`.

See [Customizing Autocomplete Layouts](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_AUTOCOMPLETE_LAYOUTS.md).

### Custom Component Overrides

Replace a component with your own implementation using the `customComponent` override prop in an unlocked configuration.

See [Custom Component Overrides](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_CUSTOM_COMPONENTS.md).

### Using the Shopify Markets Plugin

Show region-specific prices from the Shopify Storefront API on a Shopify Markets storefront.

See [Using the Shopify Markets Plugin](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_SHOPIFY_MARKETS.md).

### Using the Shopify Currency Plugin

Make the `Price` component's symbol and number format follow the Shopify storefront's active currency.

See [Using the Shopify Currency Plugin](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_SHOPIFY_CURRENCY.md).

### Per Currency Overrides

Change how one currency is displayed (for example `$1,099.99 USD` instead of `$1,099.99`) with the top level `currencies` config.

See [Per Currency Overrides](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_LOCALIZATION.md#per-currency-overrides) in the localization guide.

### Language Translations

Override the text that components display, per language, with static strings or functions — including text that changes with the active breakpoint.

See [Language Translations](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_HOW_TO_TRANSLATIONS.md).

### Tabbed Search

Let one search or autocomplete experience span multiple catalogs, with a tab per catalog.

See [Tabbed Search](https://github.com/athoscommerce/snap/blob/main/docs/REFERENCE_TABBED_SEARCH.md).
