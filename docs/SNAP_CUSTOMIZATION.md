# Customization

These pages cover features that go beyond the core [Features](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_FEATURES.md) in a standard Snap integration. Using Snap Templates? See [Templates Customization](https://github.com/athoscommerce/snap/blob/main/docs/TEMPLATES_CUSTOMIZATION.md) instead.

- **[Variants](https://github.com/athoscommerce/snap/blob/main/docs/REFERENCE_VARIANTS.md)** — build variant option pickers from `result.variants`, sync selections with the product page in realtime, and customize option labels and swatches.
- **[Quickview](https://github.com/athoscommerce/snap/blob/main/docs/REFERENCE_QUICKVIEW.md)** — preview a product in a modal or slide-out panel without leaving the results.
- **[Badges](https://github.com/athoscommerce/snap/blob/main/docs/SNAP_BADGES.md)** — display the badges configured in the console on your result cards, and create custom badge templates.
- **[Custom Recommendation Templates](https://github.com/athoscommerce/snap/blob/main/docs/REFERENCE_CUSTOM_RECOMMENDATION_TEMPLATES.md)** — create recommendation templates with the Snapfu CLI and sync them to the console.
- **[Advanced Filtering](https://github.com/athoscommerce/snap/blob/main/docs/REFERENCE_ADVANCED_FILTERING.md)** — pre-apply filters with background filters (hidden) or foreground filters (visible and removable).
